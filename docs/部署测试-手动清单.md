### ⚠️ 常见问题
- **modular router 注册失败**：看启动日志 `router registered: X` 计数，应该是 8/8
- **模型加载失败**：看日志 `models: {...}` 的 `loaded_from_hdfs` 字段，< 5 会触发训练（耗 30s-2min）
- **HBase 不可用**：seed_if_empty() 失败时，合成数据兜底（HTTP 200 但 data 可能是合成示例）

## 8. 启动 P4 Spark Streaming（**首次需下载包**）

```bash
# 8.1 拷贝作业脚本到 spark-master 容器
docker cp app\jobs\spark\streaming_visit.py spark-master:/opt/jobs/spark/
docker cp app\jobs\spark\run-streaming.sh   spark-master:/opt/jobs/spark/

# 8.2 启动（首次会下载 spark-sql-kafka 包 ~5MB，需 1-2 分钟）
docker exec spark-master bash /opt/jobs/spark/run-streaming.sh
# 期望：日志输出
#   [1/4] Kafka source subscribed to scenic_events
#   [2/4] Parsed schema
#   [3/4] Events sink started
#   [4/4] Agg sink started
#   [5/5] HBase sink started
#   === Streaming Started ===

# 8.3 测试：发 1 条事件
docker exec kafka-1 /opt/kafka/bin/kafka-console-producer.sh \
    --bootstrap-server localhost:9092 --topic scenic_events <<< \
    '{"type":"event","visitor_id":"V001","attraction_id":"A01","event_type":"enter","ts":1700000000000}'

# 8.4 验证：HBase scenic_realtime 应有新数据
sleep 35   # 等 trigger 30s
docker exec hbase-master hbase shell -n -e "scan 'scenic_realtime', {LIMIT => 3}"
# 期望：1+ 行

# 8.5 验证：HDFS 实时数据已落盘
docker exec hadoop-namenode hdfs dfs -ls -R /scenic/realtime/
# 期望：events/dt=YYYY-MM-DD/hour=HH/ + agg_attraction_5min/ 目录

# 8.6 停止
docker exec spark-master pkill -f streaming_visit
```

### ⚠️ 常见问题
- **`--packages` 下载慢**：配 .m2 mirror 或预下载
- **`foreachBatch` docker exec 失败**：检查 hbase-master 容器状态
- **Checkpoint 损坏**：删 `/scenic/realtime/_checkpoints/` 重启

## 10. 端到端业务场景（业务流验证）

| 场景 | 操作 | 期望结果 |
|------|------|---------|
| 1. 游客入园 | POST /api/reviews-stream | Kafka scenic_reviews 收到 1 条 |
| 2. 实时落 HBase | 自动（kafka_consumer 后台）| scenic_reviews 表多 1 行 |
| 3. 游客触发实时事件 | POST /api/realtime/event | Kafka scenic_events 收到 1 条 |
| 4. Spark Streaming 处理 | 自动（streaming_visit.py）| HDFS events/ + scenic_realtime 增量 |
| 5. 模型预测 | POST /api/predict {type: consumption_amount, ...} | 返回预测值 + 模型名 |
| 6. 重训 + 持久化 | POST /api/predict/retrain | HDFS /scenic/models/ 更新 |
| 7. 营销建议刷新 | GET /api/analysis/marketing-suggestions | 5 维建议文本 |
