# 🚀 快速启动指南

> 5 分钟跑通整个项目。给没用过这个项目的同学/答辩老师看。

---

## 0. 前置要求

| 工具 | 版本 | 用途 |
|------|------|------|
| **Docker Desktop** | ≥ 4.10 | 跑 17 个容器（占用 ≤ 16GB 内存）|
| **Python** | ≥ 3.10 | 跑 FastAPI 后端（**可选**，Docker 模式不需要）|
| **JDK** | 1.8 / 11 / 17 | **可选**（只在用 PySpark 训练时需要）|

> 💡 **第一次用？** 只装 Docker Desktop 就够了。其他自动用容器内的版本。

## 1. 启动大数据平台（17 容器）

### Windows
```bat
cd smart-scenic-bigdata
scripts\start.bat
```

### macOS / Linux
```bash
cd smart-scenic-bigdata
bash scripts/start.sh   # 如有
# 或
docker compose up -d
```

⏱️ 等待 3-5 分钟（首次启动要 build 镜像 + 初始化 MySQL）。

### 验证
```bat
docker ps --format "table {{.Names}}\t{{.Status}}" | findstr /R "Up "
```

应看到 17 个容器：
- `mysql`、`hadoop-namenode`、`hadoop-datanode-1/2`
- `zookeeper-1/2/3`
- `hbase-master`、`hbase-regionserver-1/2`
- `kafka-1/2`
- `spark-master`、`spark-worker-1`
- `hive-server-1/2`
- `demo-backend`

## 2. 准备 4 个 CSV 数据

数据集在 `D:\选题与数据相关资料\数据集\Topic 18\`，复制到项目：
```bash
mkdir -p data/raw_data
cp "D:/选题与数据相关资料/数据集/Topic 18/"*.csv data/raw_data/
```

> 📦 也可直接用项目仓库提供的 4 个 CSV（约 8MB，不进 git）

然后加载到 MySQL：
```bash
docker exec mysql mysql -uroot -proot123 -e "USE scenic; SHOW TABLES;"
# 首次启动会自动建表，输出应包含 4 张表：
# t_attraction / t_visitor / t_consumption / t_visit_record

# 加载 CSV
python scripts/load-csv-to-mysql.py
# 输出：t_attraction:10, t_visitor:10000, t_consumption:100000, t_visit_record:100000

# Sqoop 导入到 HDFS
docker exec hadoop-namenode bash /opt/jobs/sqoop-import-mysql.sh
```

## 5. 关于 PySpark 训练（智能双轨）

### 用户要做什么？

**不需要任何操作**。智能双轨已经处理好：
- 启动时自动检查 `/shared/models/` 是否有模型
- 有 → 直接用 PySpark 预测（推荐路径）
- 没有 → 后台自动跑 spark-submit 训练（5-10 分钟）
- 训练完自动切换到 PySpark
- 训练失败 → fallback 到 sklearn（永远可用）

### 查看训练状态

```bash
curl http://localhost:8000/api/predict/_engine
```

返回：
```json
{
  "pyspark_loader": {
    "pyspark_loaded": true,
    "models_loaded": ["regression_linear", "regression_ridge", ...]
  },
  "auto_train": {
    "models_exist": true,
    "use_pyspark":  true
  }
}
```

### 手动重训（如果需要）

```bash
# 1. 删除旧模型
docker exec spark-master rm -rf /shared/models/*

# 2. 重启后端（会自动重新训练）
docker compose restart demo-backend

# 或手动触发
docker exec spark-master bash /opt/jobs/spark-submit.sh ml-train
```

## 7. 常见问题

### Q1: `scripts\start-app.bat` 报 "Python not found"
**A**: 装 Python 3.10+，勾选 "Add to PATH"。或选模式 2（Docker 模式）。

### Q2: PySpark 模型没加载
**A**: 检查 `/api/predict/_engine`。看 `models_loaded` 字段。
- `[]` → 模型还没训练好
- `["regression_linear", ...]` → 已就绪

### Q3: 训练失败（Java 缺失）
**A**: 训练是在 spark-master **容器内**跑的，不依赖 host Java。失败原因看 backend 日志或 `docker logs spark-master`。

### Q4: HBase 报 "hbase:meta is NOT online"
**A**: Master init 慢，等 1-2 分钟重试。或：
```bat
docker exec hadoop-namenode hdfs dfs -rm -r -f /hbase
docker compose restart hbase-master hbase-regionserver-1 hbase-regionserver-2
```

### Q5: Kafka 实时流没数据
**A**: 检查 `http://localhost:8080/manage.html` 的 "Kafka 实时流" tab。
- 看 `producer.enabled` 是否 true
- 看 `consumer.running` 是否 true
- 看 `consumer.stats.messages_consumed` 数量
